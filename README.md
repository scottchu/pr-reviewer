# PR Reviewer

Help reviewers understand what a PR changes, why it matters, and what evidence supports that understanding.

This repository is starting with product intent and documentation. Start with the [product vision](docs/product/vision.md): why the product exists and what understanding a PR should feel like.

Continue with the [high-level design](docs/product/architecture.md) and [product roadmap](docs/plans/roadmap.md).

The earlier prototype remains in Playground as a reference. No application or development environment is included here yet.

Use the [documentation map](docs/README.md) to distinguish product knowledge, shared rules and delivery plans.
