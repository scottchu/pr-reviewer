# Configured-test compatibility values

This is the value/physical-format companion to [test execution](test-execution.md) and [test UI](test-ui.md). It specifies delivered engineering, not production qualification, canvas UX adoption or authority to execute, migrate, delete or replay. The [complete nonsecret vectors](test-compatibility-values.json) are normative format examples, not live qualification or process observations. All example paths are fictitious. Rebuilds preserve these representations; branded in-memory witnesses cannot be reconstructed from their JSON descriptions.

## Common value rules

Unless marked optional, every listed member is required. Nullable means an explicit JSON null; optional means absent, never a synthesized null. Public objects reject unknown members. Private historical JSON is retained without inferring new authority. Arrays preserve order. `id` is a nonempty string of at most128 JavaScript UTF-16 code units; `text` is at most1024 units (empty permitted); `n` is a nonnegative safe integer; `hash` is64 lowercase hexadecimal digits; `oid` is40 or64 lowercase hexadecimal digits; `date` is an ISO UTC datetime accepted by the current ISO datetime codec. Optional undefined fields disappear during JSON serialization. These are not interchangeable with UTF-8 byte limits.

`C(value)` recursively sorts object keys with JavaScript string `<` ordering, leaves array order unchanged, and applies compact JSON.stringify serialization without whitespace or a trailing newline. It does not normalize Unicode or path spelling. `H(bytes)` is lowercase SHA-256 hexadecimal; string inputs mean UTF-8 bytes. Digest recipes below use H(C(value)), except explicitly raw-byte hashes. Object key order is not identity; array order, absent versus null, and string contents are identity.

## Physical SQLite and private owner records

SQLite user_version remains0. Add these tables if missing; there is no test-row conversion/reset migration. An older store without test tables gains empty tables. Unknown/corrupt test bodies are not permission to manufacture jobs/results, clear exclusion or launch work.

| Table | Exact columns, keys and serialized body |
|---|---|
| test_jobs | id TEXT PRIMARY KEY; body TEXT NOT NULL. id equals jobId. body is C(stored job). SQLite rowid supplies ascending durable history order; upsert changes body, not row identity. |
| test_receipts | id TEXT PRIMARY KEY; actor TEXT NOT NULL; fingerprint TEXT NOT NULL; body TEXT NOT NULL. User command rows: id=commandId, actor=actorId, fingerprint=H(C(validated command)), body=C(command receipt). Internal admission rows: id=`test-result:` followed by jobId, actor=job actorId, fingerprint=resultId, body=C(admission receipt). |
| test_owner | id INTEGER PRIMARY KEY CHECK(id=1); generation TEXT NOT NULL. Row1 holds a fresh owner-generation UUID. It fences current in-process handles and is not a resumable grant. |

Receipt IDs share conflict checks with receipts/import_receipts/analysis_receipts/story_receipts. User command IDs must not begin `test-result:`, `analysis-admit:`, `import-admit:`, `story-internal:` or `attach:`. Same actor/exact fingerprint replays the stored receipt after authorization; different payload/actor conflicts. Reopen of an unfinished running invocation marks job and invocation unknown with unresolved effect, retaining identities/reservation and the shared execution exclusion. It never reruns the process.

A **stored job** contains every public job member below, except that each invocation is the private invocation below, plus required `credentialReference` (string), `reservedBytes` (integer), `retainedBytes` (integer). Optional private members: `stopReason` (sanitized string), `artifactLocations` (array of `{artifactId,path}` strings), `cleanupLocation` (below), `cleanupAfter` (Unix milliseconds integer). Credential reference is `local-owner:v1` for the trusted local owner or SHA-256 of a bearer; never persist the bearer here. Stop reasons match `[a-z][a-z0-9_]{0,63}`.

Queued jobs reserve2097152 bytes and retain0. Admission requires that reservation unchanged, replaces it with0, and sets retainedBytes to artifact bytes + UTF-8 length of C(next stored job with retainedBytes0/reservedBytes0) + UTF-8 length of C(admission receipt) +512. Reject if this exceeds the reservation. Quiescent unknown retains its reservation; it is not admitted evidence. Unclaimed qualification/authorization failure releases the reservation and accounts the canonical public job bytes. These accounting values are persisted, not recalculated as permission to admit historical work.

**Private invocation:** required invocationId, phase, state, quiescence as in the public invocation; optional `processJournalVersion` literal1, `processes` array, `filesystemRoots` array of root-ID strings. Missing legacy journal members are not equivalent to empty arrays. Public projection removes all three and derives optional processCount only when processes exists. A journal value is exactly `{jobId,jobRevision,invocation}` with this private invocation.

**Private process:** required `ordinal` integer1..34; `role` git_prepare/runtime_version/test_root; `state` requested/started/exited; `intentDigest` hash; `inputCount` integer0..8192; `inputBytes` integer0..532480. Optional pid positive safe integer, startIdentity string1..1024, spawnDisposition literal not_spawned, exitCode signed integer or null, signal string at most64 or null, execution (below), observationDigest hash. observationDigest hashes C(the submitted process observation without observationDigest and with undefined members omitted); merging a later observation retains prior optional fields. Requested observation has no pid/startIdentity/spawnDisposition/exitCode/signal/execution. Started has pid and no exitCode/spawnDisposition. `not_spawned` is valid only on exited without pid/startIdentity. Otherwise eligibility requires started/exited plus positive safe pid, followed by the independent read-only OS check. A recorded identity is never signaling authority. Process order is ordinal order, at most32 git_prepare then one runtime_version and one test_root; the latter is only in execute phase. Old incomplete/malformed journals stay unresolved.

**Cleanup location:** `{rootId,path,parent,device,inode,parentDevice,parentInode}`; first three strings, remaining filesystem identity numbers. This is a private locator, not public payload. **Cleanup input:** `{jobId,invocationId,resultId,attempts,location,journal}`. Public cleanup is `{state,attempts,reason}` with state pending/complete/error, attempts n, reason id or null. New admission with an owned root writes pending/0/null and cleanupAfter0. Attempt count increments (saturating at maximum safe integer); complete sets cleanupAfter0, otherwise next time is current Unix milliseconds + min(60000,1000×2^min(6,attempts−1)). Admission/quiescence/root identity and current exact journal must still match before deletion. There is no independent cleanup table or serialized deletion capability.

### Result and all nested values

Result has exactly: schema=head-test-result-v1; resultId:hash; jobId:id; invocationId:id; intent; coverage; stage:id; evidence; processes(max34); verification; state; reason:id; preparation:Preparation or null; preparationAbsence; execution; executionAbsence; output; artifacts(max16).

- intent: `{reviewId,snapshotId,actorId,repository,baseSha,headSha,targetDigest,qualificationId}`. IDs use id, repository text, commits oid, targetDigest hash, qualificationId hash or null.
- coverage: no_process_execution/partial_preparation/prepared_execution. stage is the producer's intent/source/closure/runtime/account/prepared/execution; the public decoder accepts any id, rather than narrowing legacy stage values.
- evidence: `{treeId,sourceManifestId,closureManifestId,sourceAccountId,runtimeSha256,environmentId,absentReason}`; each identity is its appropriate oid/hash or null. absentReason is always not_completed, even when all values exist.
- processes item: `{ordinal,role,state,exitCode,signal,execution,executionAbsence}`. ordinal n; role/state id; exitCode signed integer or null; signal id or null; execution null or `{executable:id,argv:text[](max64),cwd:id,attemptedAt:date,startedAt:date|null,exitedAt:date|null}`; executionAbsence is not_observed when missing, otherwise null. Public process evidence omits pid/startIdentity/private intent hashes. Producer sanitizes executable/root locators to `<fixed-git>`, `<qualified-bun>`, `<owned-root>`, `<source-repository>`.
- verification: `{pre,post,absenceReason:"not_reached"}`. Each phase null or `{observedAt:date,inputs:"verified"|"error",overlays:"verified"|"error",sourceDigest:hash|null,expectedSourceDigest:hash|null,changedEntries:n|null,overlayDigest:hash|null,files:n,bytes:n,reason:id|null}`. The absenceReason member remains present even with both observations.
- state: passed/failed/cancelled/timed_out/unavailable/error. Unknown is a job/effect disposition, never an admitted Result state. reason is required nonempty id.
- preparationAbsence is not_completed when preparation=null, else null. execution is null or `{exitCode:integer|null,signal:id|null,collectionObserved:boolean,counts:null|{passed:n,failed:n,total:n}}`. executionAbsence is not_started when null, else null. Counts are observed collection, not inferred from exit0; their total must equal passed+failed for producer acceptance.
- output: `{observedBytes:n,retainedBytes:n,overflow:boolean}`. artifacts contains complete descriptors, not local file locators.

These schema checks do not suffice for admission. Consumers verify result job/invocation/state and intent match the selected job, its actor/repository/base/head/target/qualification, and resultId is H(C(the entire Result with resultId omitted)). Current owner witnesses/journal/control, quota, cancellation/deadline and quiescence still gate admission.

## Artifact registry and identity recipes

Artifacts are raw bytes in an explicitly configured existing artifact root. A publication makes a new UUID directory via a sibling `.<publicationUUID>.staging`, writes UUID-named files exclusively with mode0600 in mode0700 staging, verifies bytes/hash, then renames to `<artifactRoot>/<publicationUUID>`. The stored job's artifactLocations pairs each artifactId with that final absolute path. There is no separate registry table, locator file or JSON wrapper around process output. A descriptor alone cannot reconstruct a location or authorize an arbitrary path read.

source_evidence bytes are UTF-8 C(`{source,closure,account,metadata,overlays,inputVerification}`), each member its complete value below or null. Output artifacts are raw concatenated observed chunks, ordered by role git_prepare/runtime_version/test_root, then stdout/stderr; labels are `<role>.<channel>`. No chunk means no corresponding artifact. source_evidence label is source_evidence. Total artifact bytes must be≤2097152−32768 before admission's further quota check.

## Exact compiler configuration qualification

A root tsconfig.json, if present, must parse as strict JSON (fatal UTF-8 decoding) and canonically equal this entire value. Key order/whitespace may vary; array order and explicit presence may not. Omitted defaults are not equivalent. Absent root tsconfig.json is allowed by this check and produces no resolutionConfigs entry; the test closure's other requirements still apply. This does not impose a new repository config file.

```json
{"compilerOptions":{"target":"ES2023","lib":["ES2023","DOM","DOM.Iterable"],"module":"NodeNext","moduleResolution":"NodeNext","strict":true,"noUncheckedIndexedAccess":true,"exactOptionalPropertyTypes":true,"jsx":"react-jsx","allowImportingTsExtensions":true,"noEmit":true,"skipLibCheck":true,"types":["node","bun"]},"include":["src","scripts","tests","playwright.config.ts"]}
```

Accepted: that value with reordered object keys; absent root config. Rejected: missing skipLibCheck, strict=false, added paths/baseUrl/extends, different include order, additional exclude, JSON comments/trailing commas, or nested/alternate tsconfig/jsconfig even if otherwise identical. Scan basenames case-insensitively for `tsconfig[.*].json`, `jsconfig[.*].json`, package.json, but accept only exact root paths tsconfig.json and package.json. Root package must be an object with name=pr-reviewer and none of imports/exports/browser/alias/workspaces, even if those forbidden values would be empty. Package/lock closure compatibility additionally remains required.

## Separate private test-intent protocol

Storage medium is same-tab sessionStorage, not SQLite, localStorage or the question recovery record. Exact key is `pr-reviewer:test-intent:v1:` + encodeURIComponent(origin) + `:` + encodeURIComponent(reviewId) + `:` + encodeURIComponent(ownerScope). Runtime origin is location.origin (scheme/host/port, no path); nonbrowser default is local. Default/current local-owner scope is the literal nonsecret local-owner:v1. For a legacy bearer access lifecycle, the bridge uses lowercase SHA-256 UTF-8 of `pr-reviewer-credential-scope-v1` + NUL + decimal UTF-8 byte length of origin + `:` + origin + decimal UTF-8 byte length of trimmed bearer + `:` + trimmed bearer. Do not store the bearer. The standalone session factory defaults to local-owner:v1; the application supplies the derived legacy scope on setAccess. Local owner does not use the question protocol's hashed local-owner scope.

Envelope is JSON.stringify of exactly the writer members `{version:1,origin,reviewId,ownerScope,scope,command,receipt}`. Scope and command have the exact strict shapes above. Receipt is explicit null or the command receipt. Reader tolerates extra envelope members but nested codecs reject extras. Receipt must match commandId and original review/snapshot; CancelTest receipt also matches jobId. RequestTest command's scope must match envelope scope. There is no fingerprint field, stored request-byte string, expiry, submitted list, or explicit phase discriminator. Phase is determined by receipt: null means prepared/uncertain intent (cannot distinguish unsent from response lost); nonnull means accepted-awaiting-authoritative-readback. The command object is reserialized unchanged on explicit recovery; it is not question recovery's exact-byte-string format.

There is **no additional whole-record UTF-8 size cap** or truncation policy in this implementation. Shape limits above bound fields; browser storage quota can still fail. Reads do not impose a byte preflight. Save uses setItem without separate read-after-write verification; clear uses removeItem without equality readback. Do not invent a silent truncation or new limit as compatibility behavior. This records the existing contract, not a claim of platform persistence beyond the same browser session.

Before dispatch, save the whole envelope with receipt=null. Unknown transport/timeout/parse/integrity failure retains it and blocks new intent. Persist the validated receipt before requesting its exact job with minimumJobRevision. Clear only after matching scope/job and a job revision≥receipt revision passes contextual result verification. Explicit recovery with a receipt reads; it does not resend the command. Explicit recovery without a receipt resends the same command ID/object/expected revision. Authoritative HTTP400/401/403/404/409 rejection may clear after removeItem succeeds. Storage errors surface test_storage_unavailable; no dispatch occurs if the first save fails. Invalid record on read surfaces test_recovery_invalid and blocks mutations; it is not absence and is not silently removed.

Only raw absence returns no recovery. Unknown version, malformed JSON, absent receipt, invalid scope/command/receipt or same-key envelope origin/owner/review mismatch are invalid. A changed origin/review/owner uses a different key and leaves the previous record untouched; it does not retarget or migrate it. Older/future schemas, old question keys and arbitrary keys are not imported. Same-tab legacy bearer scope is supported only through its derived key, not a migration to local-owner scope. Snapshot navigation can display a pending old scope but cannot rewrite its command. Selecting that scope with a retained receipt automatically reads the original job; an uncertain record is never auto-resubmitted. Access replacement aborts/fences prior reads before switching private scope. Disconnect aborts slots/timer but preserves the stored intent. No reset/quarantine UI or universal converter is implied.

The vectors include complete receipt-null and receipt-present envelopes plus the encoded key. They are deliberately nonsecret local-owner examples; injecting one into a different origin/key is a mismatch test, not valid recovery.

The whole-job examples are independent format vectors, not successive observations of one process history. Synthetic source/process fields exercise nested values without claiming the witnesses needed to admit them. Readers must preserve the optional/null distinctions and recompute the supplied canonical digests; passing a public codec alone does not authorize replay, admission or cleanup.
